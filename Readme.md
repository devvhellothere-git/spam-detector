# 📩 Spam SMS Detector

A machine learning app that detects whether an SMS message is spam or not.

🔗 **Live App:** [Click here to try it](https://spam-detector-hellothere.streamlit.app/)

## Tech Stack
Python · Scikit-learn · Streamlit · TF-IDF · Naive Bayes

## Model Performance
Accuracy: 97%

## How it works
1. User enters any SMS message
2. Model classifies it as Spam or Not Spam
3. Result is shown instantly

## Example Messages
1. **🚨 Spam Message:** Congratulations! You have won a FREE iPhone 15! Click here to claim your prize now: www.free-prize.com. Limited time offer. Reply WIN to 9876543210
2. **✅ Not Spam Message:** Hey, are you coming to college tomorrow? Let me know so we can travel together.
